# Template Tugas Nyata (Tangible Task Template)

Gunakan format ini di setiap akhir respons pembelajaran:

---

```markdown
### 🎯 MISSION TASK: [Nama Tugas Singkat]

**Tujuan:**  
[1 kalimat hasil akhir yang terukur dan berfungsi]

**Waktu Target:**  
⏱️ [15 - 30 Menit]

**Langkah Eksekusi (Do):**  
1. [Langkah konkret 1 — buka file / wiring pin X ke Y]
2. [Langkah konkret 2 — tulis kode / pasang komponen]
3. [Langkah konkret 3 — jalankan perintah tes / ukur tegangan]

**Expected Result (Hasil yang Diharapkan):**  
[Contoh output terminal, response JSON, LED menyala, atau model 3D ter-render]

**Success Criteria:**  
- [ ] Fitur berjalan tanpa runtime error.
- [ ] Bukti tersimpan (git commit / log output / foto rangkaian).

---

**🧠 Quick Recall Check (Uji Ingat Cepat):**  
[1 pertanyaan singkat menguji pemahaman konsep 20% yang baru saja dipelajari tanpa membuka contekan]
```
